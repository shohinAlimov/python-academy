# Python Задачи · shohin's Academy

Сайт с задачами по Python, автоматической проверкой, аккаунтами, профилями и общим просмотром решений.
Стек: Node.js + Express + MongoDB 5.0 или новее + Docker для запуска Python.

## Запуск

1. Создайте бесплатную базу в MongoDB Atlas (cloud.mongodb.com) → Connect → Drivers → скопируйте строку подключения.
   В Atlas → Network Access добавьте свой IP (или 0.0.0.0/0 для хостинга).
2. Скопируйте `.env.example` в `.env` и заполните:
   - `MONGODB_URI` — строка из Atlas (после `.net/` укажите имя базы, например `python_academy`)
   - `JWT_SECRET` — длинная случайная строка. Сгенерировать: `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"`
3. Запустите Docker с Linux-контейнерами и скачайте образ Python командой `docker pull python:3.13-slim`.
4. Установите и запустите:
   ```
   npm install
   npm start
   ```
5. Откройте http://localhost:3000

Локально можно вместо Atlas поставить MongoDB Community и указать `mongodb://127.0.0.1:27017/python_academy`.

## Страницы
`index.html` главная · `topic.html?t=vars` задачи темы · `people.html` сообщество ·
`profile.html` свой профиль · `profile.html?u=логин` чужой профиль · `login.html` вход и регистрация.

## Как это устроено
- Пароли хранятся как bcrypt-хеш, вход — httpOnly-cookie с JWT на 30 дней.
- Коллекции: `users` (логин, хеш, имя, аватар, о себе) и `solutions` (userId, номер задачи, код, время, признак проверки). Прогресс считается по сохранённым решениям.
- Ограничения: 10 регистраций в час и 10 попыток входа за 15 минут с одного IP; код до 20 000 символов.
- Код других пользователей показывается только как текст (HTML экранируется).

## Автопроверка

- Нажмите «Проверить решение» на странице задачи. Сайт проверяет вывод или поведение функций и классов по учебным тестам из `grader.py`.
- Если все тесты пройдены, решение сохраняется в аккаунте или, в гостевом режиме, в браузере. При ошибке редактор показывает причину, а последнее принятое решение остаётся в прогрессе. Решения, сохранённые до появления автопроверки, учитываются в прежнем прогрессе и помечены в редакторе как ранее сохранённые.
- Каждый запуск получает отдельный контейнер без сети, подключённых папок и секретов приложения. Контейнер работает с файловой системой только для чтения и ограничениями на время, память, процессы и объём вывода.

## Выкладка в интернет
Для автопроверки нужен хост с доступными Docker CLI и Docker Engine для Linux-контейнеров. Заранее скачайте образ командой `docker pull python:3.13-slim`. При необходимости другой подготовленный образ можно указать через `GRADER_IMAGE`.
Задайте `MONGODB_URI`, `JWT_SECRET` и `NODE_ENV=production` (включает secure-cookie, нужен HTTPS). Команда запуска — `npm start`.
